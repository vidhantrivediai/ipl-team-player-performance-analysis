# IPL Team and Player Performance Analysis

## Project Overview
This project analyzes Indian Premier League (IPL) cricket data using Python. It provides an interactive dashboard to understand team and player performance.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Features
- Team-wise Match Wins
- Team Win Percentage
- Season-wise Match Analysis
- Top 10 Batsmen
- Batting Strike Rate
- Top 10 Bowlers
- Bowling Economy
- Interactive Data Visualization

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run Project

```bash
streamlit run main.py
```

Upload `matches.csv` and `deliveries.csv` through the dashboard sidebar.
